# spotfity

Projeto de estudo inspirado na interface do Spotify, desenvolvido com HTML, CSS e Bootstrap 5.

## Estado atual

Em desenvolvimento: contém uma barra de navegação responsiva e textos provisórios no corpo da página. Os links de navegação ainda são marcadores e não há reprodução de músicas, cadastro ou autenticação.

## Visualizar

Abra `index.html` no navegador.

## Estrutura

- `index.html`: página principal.
- `css/estilo.css`: estilos personalizados.
- `css/`: arquivos de estilos do Bootstrap.
- `js/`: scripts do Bootstrap.
- `imagens/`: imagens e logo utilizados no estudo.

Este é um projeto educacional independente, sem vínculo oficial com o Spotify.
